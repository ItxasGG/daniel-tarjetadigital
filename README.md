## 💎 Estética & Elementos de Diseño Liquid Frosted Glass
1. **Lienzo cinematográfico de fondo (`bg.jpg`)**: Atmósfera nocturna con desenfoque de movimiento, sombras pizarras/cian y destellos dorados bokeh.
2. **Cápsulas de vidrio esmerilado (Glassmorphism)**: `backdrop-filter: blur(28px) saturate(190%)`, bordes especulares con refracción de luz (`border-top: 1.5px solid rgba(255,255,255,0.38)`) y esquinas redondeadas hiper-táctiles (`border-radius: 26px`).
3. **Hero Card**: Fotografía de Daniel integrada en cápsula circular con bisel de cristal, titular nítido, escala técnica con aguja indicadora y la frase *«Consultoria personalizada para tu negocio»*.
4. **Grid modular 2x2 táctil**:
   - **WhatsApp**: Chat directo con barra deslizante y puntero de disponibilidad activa.
   - **Llamar**: Conexión telefónica directa con ecualizador gráfico de señal de audio.
   - **Email**: Correo corporativo con medidor de respuesta rápida.
   - **Catálogo 2026**: Apertura del visor modal con las 4 gamas de peluquería (Coloración, Tratamientos, Styling y Herramientas).
5. **Botón Guardar Contacto (.vcf)**: Descarga automática de `Daniel_Vega_Soto.vcf` (vCard 3.0) para iOS y Android.
6. **Código QR y Web Share**: Botones flotantes circulares (`⤢` y `↻`) y puntos de paginación (`● ● ●`).
