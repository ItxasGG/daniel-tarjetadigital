## ✨ Características clave
1. **Un solo archivo autocontenido (`index.html`)**: Integra estructura HTML5 semántica, diseño CSS responsive y lógica JavaScript sin dependencias externas.
2. **Descarga vCard (.vcf) directa**: Botón «Guardar contacto» compatible con la agenda de iOS (Apple Contacts) y Android (Google Contacts).
3. **Catálogo interactivo integrado**: En lugar de redirigir a una web externa, el botón «Ver catálogo» despliega un modal con las líneas principales para salones (Coloración técnica, Tratamientos avanzados, Styling y Herramientas/Utillaje) y acceso directo para solicitar tarifas en PDF por WhatsApp.
4. **Código QR integrado**: Permite mostrar el código QR en pantalla para que clientes o estilistas en salones y ferias puedan escanear la tarjeta en persona.
5. **Web Share API**: Botón para compartir mediante el menú nativo del móvil o copiar el enlace al portapapeles con confirmación visual (toast flotante).
6. **Resiliencia visual**: Incluye la fotografía adjunta tanto referenciada como embebida en Base64 para garantizar que la imagen siempre cargue, incluso si el archivo HTML se comparte de forma aislada.
